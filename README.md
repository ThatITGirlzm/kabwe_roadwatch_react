# Kabwe RoadWatch — React + TypeScript

## Run the project

1. Install Node.js (LTS).
2. Open a terminal in this project folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite.

## Structure

- `index.html` — Vite HTML entry.
- `src/main.tsx` — React entry point.
- `src/App.tsx` — React application and components.
- `src/App.css` — original CSS from the supplied MVP.

## Backend status

This is the frontend-only demonstration MVP. Reports and staff sign-in remain in browser memory; Django REST Framework and PostgreSQL are not connected.
